# Source provenance

This repository originated as a fork of `hndko/payload-injector-generator`.

The original upstream repository was inspected during development. This
professional edition adds a new Flutter application, a Dart engine, Go engine,
Python compatibility tooling, tests, CI, and documentation.

Verify the upstream repository's current licensing terms before redistributing
upstream-derived source. New PayloadLab source is provided as project source;
no claim is made here about the upstream project's license.
